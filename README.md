# Ninh AI - Flutter Starter

Starter source for the Ninh AI Android learning + game application.

## Requirements
- Flutter SDK (stable)
- Android Studio or Flutter-compatible development environment
- Android SDK

## Run
```bash
flutter pub get
flutter run
```

## Build Android APK
```bash
flutter build apk --release
```

APK output:
`build/app/outputs/flutter-apk/app-release.apk`

## Current scope
- Flutter application entry point
- Material 3 theme
- Home dashboard
- Bottom navigation
- Learning, pet, and profile placeholder tabs
- XP, level, and daily quest UI placeholders

Authentication, backend, database, and AI tutor are not connected yet.
They will be implemented in later steps. Do not put private API keys in the app.
